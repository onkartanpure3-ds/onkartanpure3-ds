## 📊 Dashboards & Analytics

### 2) 🚦 Road Accident Dashboard `Tableau`

Interactive Tableau dashboard analysing **660,679 road accident records (2019–2022)** across severity, road type, surface condition, weather, lighting, vehicle type and location.

- Tracks accident counts and casualties by severity (fatal, serious, slight)
- Compares current year vs previous year using Tableau **parameters and calculated fields**
- Geographic analysis with **Tableau maps** across 422 district areas
- Python + pandas notes for exploring the raw CSV

**Key Results:**
- **660,679** accident records · **896,568** total casualties
- 2021 vs 2020: accidents **−4.13%**, casualties **−3.79%**
- Fatal casualties fell the most: **−11.80%** (4,398 → 3,879)

**Tech:** Tableau · Calculated Fields · Parameters · Maps · Python · Pandas

🔗 Repo: https://github.com/onkartanpure3-ds/Road-Accident-Dashboard

### 3) 🏅 Olympics Analysis Dashboard `Power BI`

Interactive Power BI dashboard exploring Olympic medal distribution, participating countries, gender-based performance and top athletes.

### 4) 🛒 Super Store Sales Dashboard `Power BI`

Interactive Power BI dashboard to explore sales and profit by customer segment, category, payment mode, ship mode and region.

- Region slicer (Central, East, South, West)
- Sales and profit trends over time
- Breakdowns by category, sub-category, payment mode and shipping mode

**Key Insights:**
- **Consumer** is the largest segment (49.24%), ahead of Corporate (30.77%) and Home Office (19.99%)
- **COD** is the most-used payment mode (40.87%), followed by Online (38.77%)
- **Office Supplies** leads on number of sales

**Tech:** Power BI Desktop · Excel dataset

🔗 Repo: https://github.com/onkartanpure3-ds/Super-store-Sales-Dashboard
